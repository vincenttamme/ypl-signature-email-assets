# YPL / Y247 Group email signature assets

This public repository contains four owner-approved brand/contact PNGs and one generic Lucide Share2 PNG used by YPL Signature Studio, their manifest, and the Lucide ISC license.

Each file is stored under a directory named with the first 12 characters of its SHA-256. For immutable CDN URLs, pin the repository reference to the publication commit SHA rather than a branch name. Example path pattern:

`https://cdn.jsdelivr.net/gh/vincenttamme/ypl-signature-email-assets@<commit-sha>/email-assets/v1/<sha256-prefix>/<logos-or-icons>/<filename>`

The generic Lucide Share2 glyph is used before social-link labels; it is not presented as an Instagram, LinkedIn, TikTok, or YouTube logo. Company social links remain administrator-configured and no account URLs are included. The application activates the PNG only through the validated immutable URL; email labels remain visible when images are blocked.
