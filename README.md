# YPL / Y247 Group email signature assets

This public repository contains only the four owner-approved PNGs used by YPL Signature Studio, their manifest, and the Lucide ISC license.

Each file is stored under a directory named with the first 12 characters of its SHA-256. For immutable CDN URLs, pin the repository reference to the publication commit SHA rather than a branch name. Example path pattern:

`https://cdn.jsdelivr.net/gh/vincenttamme/ypl-signature-email-assets@<commit-sha>/email-assets/v1/<sha256-prefix>/<logos-or-icons>/<filename>`

The application must only activate URLs after the exact remote response has passed the repository validator. No social-brand logos or account links are included.
