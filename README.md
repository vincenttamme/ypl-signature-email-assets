# YPL / Y247 Group email signature assets

This public repository contains approved company logos, contact pictograms, selected social-brand PNGs, generic Lucide pictograms, their manifest, and the Lucide ISC license.

Each file is stored under a directory named with the first 12 characters of its SHA-256. For immutable CDN URLs, pin the repository reference to the publication commit SHA rather than a branch name. Example path pattern:

`https://cdn.jsdelivr.net/gh/vincenttamme/ypl-signature-email-assets@<commit-sha>/email-assets/v1/<sha256-prefix>/<logos-or-icons-or-social>/<filename>`

Lucide contact and website pictograms are transparent white PNGs. Instagram is available as the original gradient glyph and as a white monochrome raster derived from the official glyph artwork while preserving its alpha contour. LinkedIn and YouTube are supplied as official white assets. The application only exports a PNG whose registered color matches the society's configured icon color; otherwise it keeps the text link.

The generic Lucide Share2 glyph is not presented as a social-brand logo. Company social links remain administrator-configured and no account URLs are included. No TikTok mark is hosted until written permission is available.
